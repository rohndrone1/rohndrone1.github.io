What is available in the current prototype?

The local prototype includes enrolled face and voice matching, transcription, evidence-linked conversation memory, questions and answers, follow-up suggestions, routine completion reports, and a care request that appears on an open family screen. The browser interface connects to a Python backend on a Mac.

The example screens on this page illustrate fictional use cases. A guided demonstration of the local backend is available on request. Continuous all-day operation and clinical benefits have not been established.

How are memory and uncertainty handled?

A plan is stored separately from a reported completion. New information can close a resolved follow-up. The backend checks supporting source references, and uncertain speaker matches are excluded from attributed memory. These checks reduce errors; real-world evaluation is still needed.

COMMUNITY SUPPORT

Connecting families
with more help.

When a wearer asks for someone, ContextCue puts a request on an open family screen so a person can check in. If the family needs ongoing help, ACL’s Eldercare Locator can connect them with local aging services. ContextCue could also be offered through aging-service organizations in the future.
